# Use cases

Рецепты для решения реальных проблем с субтитрами. Каждая страница формулирует задачу, а
затем пошагово показывает команды `sm`, которые её решают — с готовыми файлами-примерами,
ожидаемым выводом, предварительным просмотром через `--dry-run` и примером `--output json`
для скриптов.

Это рецепты, а не справочник по флагам. Полный список параметров любой команды:
`sm <command> --help`; машиночитаемые схемы: `sm describe`.

## Соглашения, используемые в рецептах

- **`--out` — файл результата; `--output text|json` — глобальный флаг формата вывода.**
  Это разные флаги — `merge`, `rescale` и `concat` записывают результат в `--out`.
- **Изменяющие команды создают резервную копию** в `backups/` перед изменением файла на
  месте; все они поддерживают `--dry-run` для предварительного просмотра.
- **Отрицательные смещения:** ставьте флаги опций перед отрицательным смещением
  (`sm delay --dry-run file -500`), иначе ведущий `-` будет воспринят как флаг.
