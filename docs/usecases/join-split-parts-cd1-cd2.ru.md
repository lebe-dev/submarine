# Склейка частей (CD1/CD2) в один файл

> Релиз разбит на два файла, воспроизводимых последовательно — склейте их в один, со сдвигом второй части вслед за первой.

## Сценарий

Старый релиз поставляется в виде `CD1` и `CD2`, каждый из которых начинает временны́е коды
с нуля. При воспроизведении как единого видео реплики второго файла должны начинаться там,
где заканчивается первый. `sm concat` добавляет части и сдвигает каждую последующую
на накопленную сумму, затем перенумеровывает результат.

Это отличается от [merge](merge-incomplete-translation-with-donor.ru.md): части **не**
перекрываются по времени — они идут последовательно.

## Используемые команды

- `sm concat` ★ — добавить части и сдвинуть каждую вслед за предыдущей
- `sm info` — подтвердить итоговую продолжительность и количество реплик

## Файлы-примеры

`part1.srt`:

```srt
1
00:00:01,000 --> 00:00:03,000
CD1 first line.

2
00:00:04,000 --> 00:00:06,000
CD1 last line.
```

`part2.srt` — также начинается около нуля:

```srt
1
00:00:01,000 --> 00:00:03,000
CD2 first line.

2
00:00:05,000 --> 00:00:07,000
CD2 last line.
```

## Пошаговая инструкция

### 1. Предварительный просмотр с `--dry-run`

`--gap` задаёт тишину (в мс), вставляемую между частями:

```bash
sm concat part1.srt part2.srt --out full.srt --gap 2000 --dry-run
```

```
Dry-run: subtitles would be concatenated

Parts: part1.srt, part2.srt
Gap: 2000 ms
Total subtitles: 4
Output: full.srt
```

### 2. Применить

```bash
sm concat part1.srt part2.srt --out full.srt --gap 2000
```

```
✓ Subtitles concatenated successfully

Parts: part1.srt, part2.srt
Gap: 2000 ms
Total subtitles: 4
Output: full.srt
Backup: N/A (new file)
```

`full.srt` содержит часть 1 без изменений, затем часть 2, сдвинутую так, чтобы она
начиналась после окончания части 1 плюс пауза, с последовательной перенумерацией индексов:

```srt
1
00:00:01,000 --> 00:00:03,000
CD1 first line.

2
00:00:04,000 --> 00:00:06,000
CD1 last line.

3
00:00:09,000 --> 00:00:11,000
CD2 first line.

4
00:00:13,000 --> 00:00:15,000
CD2 last line.
```

### 3. Подтвердить

```bash
sm info full.srt
```

Убедитесь, что **Total subtitles** и **Total duration** соответствуют двум частям плюс паузе.

## JSON-вывод

```bash
sm --output json concat part1.srt part2.srt --out full.srt --gap 2000 --dry-run
```

```json
{"ok":true,"data":{"parts":2,"gap_ms":2000,"total_count":4,"output":"full.srt","dry_run":true}}
```

- `parts` — количество объединённых входных файлов.
- `gap_ms` — тишина, вставленная между частями.
- `total_count` — реплики в результате.

## Подводные камни и граничные случаи

- **Каждая часть сохраняет свой начальный отступ.** Часть 2 начиналась с `00:00:01,000`,
  поэтому после части 1 (заканчивается в `00:00:06,000`) плюс пауза 2 с она встаёт на
  `00:00:09,000` — собственный 1-секундный отступ части сохраняется поверх паузы.
  Обрежьте ведущую тишину части заранее, если хотите, чтобы пауза была точной.
- **Порядок важен.** Части объединяются слева направо в том порядке, в котором вы их
  указываете.
- **`--out`, а не `--output`.** `--out` — файл результата; `--output text|json` — глобальный
  флаг формата.
- **Перекрываются, а не следуют последовательно?** Если части разделяют диалог по времени,
  вам нужен [merge](merge-incomplete-translation-with-donor.ru.md) вместо concat.
