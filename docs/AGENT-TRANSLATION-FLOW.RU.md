# Поток перевода субтитров через агента

Как перевести субтитры с одного языка на другой с помощью submarine и LLM-агента (Codex, Claude Code, opencode, etc.).

Например, вы хотите перевести 8-ю серию 3-го сезона сериала **Resident Alien** на русский язык.

**Требования:**
- Установленный Submarine CLI
- Установленный Agent
- Файл английских субтитров для 3-го сезона Resident Alien

Поместите в `CLAUDE.md` / `AGENTS.md` / `GEMINI.md`:

###[AGENTS.md]#######################################################

```markdown
## Рабочий процесс перевода субтитров

Вы переводите субтитры с английского на русский с помощью CLI-инструмента `sm`.

### Шаг 1: Проверка статуса

touch Resident.Alien.rus.srt

sm translation-status --reference=Resident.Alien.S03E08.eng.srt Resident.Alien.S03E08.rus.srt

Эта команда покажет прогресс и предложит следующий диапазон для перевода.

### Шаг 2: Извлечение фрагмента для перевода

sm export --format=anchored Resident.Alien.S03E08.eng.srt 1-100

Формат вывода:

[1] Английский текст здесь
[2] Ещё английский текст
...

### Шаг 3: Перевод и сохранение во временный файл

Создайте файл `chunk.txt` с переводами в том же формате:

[1] Русский перевод
[2] Ещё русский текст
...

ВАЖНО: Сохраните ВСЕ индексы. Не пропускайте ни одной строки.

### Шаг 4: Импорт переводов

sm import --force --reference=Resident.Alien.S03E08.eng.srt --format=anchored Resident.Alien.S03E08.rus.srt chunk.txt

### Шаг 5: Проверка фрагмента

sm verify --range=1-50 Resident.Alien.S03E08.eng.srt Resident.Alien.S03E08.rus.srt

Если обнаружены пропущенные индексы, извлеките только их:

sm export --format=anchored Resident.Alien.S03E08.eng.srt 40-41

Переведите пропущенные строки, добавьте их в `chunk.txt` и снова выполните импорт.

### Шаг 6: Повтор для следующего фрагмента

Удалите `chunk.txt`.

sm translation-status --reference=Resident.Alien.S03E08.eng.srt Resident.Alien.S03E08.rus.srt

Продолжайте, пока прогресс не достигнет 100%.

### Правила

- Размер фрагмента: 100 субтитров
- Всегда проверяйте после импорта
- Исправляйте все пропуски перед переходом к следующему фрагменту
- Сохраняйте исходный смысл, адаптируйте идиомы естественным образом

###[/AGENTS.md]#######################################################

Запустите агента и дайте ему следующий промпт:

```prompt
Давайте переведём субтитры для 8-й серии 3-го сезона сериала Resident Alien.
Возьмите английские субтитры из `Resident.Alien.S03E08.eng.srt` и используйте инструмент `sm`.

Ожидаю получить `Resident.Alien.S03E08.rus.srt` в результате.
```
